# Всесвіт Звуків

Офіційний сайт корекційного клубу та занять у групі «Всесвіт Звуків» у Кривому Розі.

🌐 **https://www.vsesvit-zvukiv.com.ua**

## Про проєкт

- Корекційний клуб: логопедична корекція, запуск мовлення, діагностика, ABA-терапія, сенсорика.
- Заняття у групі: повний день, половина дня, гнучкий графік.
- Сторінки: головна, корекційний клуб, заняття у групі, ціни, фахівці, про нас, контакти.

## Технології

React 18 · Vite · Tailwind CSS · Motion · GitHub Pages · Cloudflare

## Про цей репозиторій

Тут лежить лише зібрана версія сайту (гілка `gh-pages`), яку обслуговує GitHub Pages.
Вихідний код зберігається в окремому приватному репозиторії та публікується сюди автоматично.
